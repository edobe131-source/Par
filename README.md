# Par

브라우저에서 돌아가는 2D 플랫포머 게임입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 현재 기능

- **월드 선택**: 지금은 월드 1만 있음 (`js/worlds.js`에 항목을 추가하면 늘어남)
- **플레이**: 좌우 이동, 점프 (길게 누르면 높이, 짧게 누르면 낮게), 낭떠러지에 떨어지면 스타트로 복귀
- **맵 에디터** (개발자 인증 필요)
  - 플레이 화면 오른쪽 위 `개발자` 버튼 → 인증 코드 입력
  - 도구: 일반 블록 / 스타트 / 지우개
  - 스타트는 맵에 딱 1개만 존재: 새 위치에 놓으면 기존 스타트가 옮겨지고, 블록이나 지우개로는 지워지지 않음
  - 열려 있는 동안 **1분마다 자동 저장** (변경 사항이 있을 때). 에디터를 나가거나 탭을 닫을 때도 저장
  - `테스트`로 편집 중인 맵을 바로 플레이해 볼 수 있음
  - `맵 문자열`에서 현재 맵 문자열을 복사하거나, 다른 문자열을 붙여넣어 적용 가능

## 조작

| 화면 | 키 |
| --- | --- |
| 플레이 | ←→ / A D 이동 · Space / ↑ / W 점프 · R 처음으로 · Esc 월드 선택 |
| 에디터 | 좌클릭 배치 · 우클릭 지우기 · 1 블록 · 2 스타트 · 3 지우개 · WASD/방향키/마우스 휠/가운데 버튼 드래그 화면 이동 (Shift: 빠르게) · P 테스트 · Ctrl+S 저장 · Esc 나가기 |

## 맵 문자열 형식

맵 하나는 문자열 하나로 저장됩니다.

```
PAR1:<1행>/<2행>/.../<마지막 행>
```

- 위쪽 행부터 `/`로 구분하며, 모든 행의 길이가 같아야 함
- `.` 빈칸 · `#` 일반 블록 · `S` 스타트 (정확히 1개)
- 맵 크기는 문자열에서 정해짐 (행 길이 = 가로, 행 개수 = 세로)

## 저장 위치

에디터에서 저장한 맵은 **이 브라우저의 localStorage**(`par.world1.map`)에만 저장됩니다.
다른 브라우저/기기나 다른 사람에게는 반영되지 않으므로, 맵을 게임 기본값으로 확정하려면
`맵 문자열`에서 복사해 `js/worlds.js`의 `defaultMap`에 넣어야 합니다.

## 파일 구성

```
index.html        화면 구성
css/style.css     스타일
js/sha256.js      개발자 코드 확인용 해시
js/map.js         맵 데이터 · 문자열 변환 · 저장
js/worlds.js      월드 목록과 기본 맵
js/input.js       키보드 입력
js/render.js      그리기
js/play.js        플레이어 물리 · 충돌 · 카메라
js/editor.js      맵 에디터
js/auth.js        개발자 인증
js/main.js        화면 전환 · 메인 루프
```

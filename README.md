# Par

브라우저에서 돌아가는 2D 플랫포머 게임입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 현재 기능

### 플레이
- **월드 선택**: 카드에 그 월드에서 모은 별 / 전체 별, 제목 옆에 모든 월드에서 모은 별 합계 표시
  - 월드마다 **열리는 데 필요한 별**이 있어서, 모은 별 합계가 그보다 적으면 잠김(`🔒 ★ N 필요`, 누를 수 없음)
  - 개발자는 잠긴 월드에도 들어갈 수 있음
- **이동/점프**: 길게 누르면 높이, 짧게 누르면 낮게 점프
- **비탈**: 픽셀 2칸(8px) 이하의 턱은 걸어서 올라서고, 내려가는 계단·비탈에는 붙어서 걸어 내려감. 기울어진 블록 위도 비탈처럼 다님
- **체크포인트**: 스타트 포함. 직접 가서 닿아야 등록되고, 마지막으로 닿은 체크포인트에서 부활. 에디터에서 이름을 붙일 수 있음
  - `C` 키(또는 `체크포인트` 버튼)로 등록한 체크포인트 아무 데나 이동 가능 — **떨어지는 중에는 이동 불가**
- **별**: 닿으면 획득해서 별 개수 +1. 한 번 먹은 별은 다시 먹을 수 없음
- **가시**: 닿으면 죽고 현재 체크포인트에서 부활. 판정은 그린 픽셀 그대로 (아래 '판정' 참고)
  - 가시: 1/3 크기 가시 3개가 붙은 모양 · 단일 가시: 1/3 크기 가시 1개 (왼쪽 · 가운데 · 오른쪽 중 골라서 놓음) · 큰 가시: 칸 크기 가시
- **특수 블록**
  - 얼음: 위에서 미끄러짐
  - 머신: 위에 있으면 가만히 있어도 왼쪽/오른쪽(놓을 때 고름)으로 이동
  - 벽: 옆에 딱 붙어 있으면 아래에 블록이 없어도 계속 점프 가능 (벽 타고 오르기)
  - 구름: 닿기만 하면 파묻혔다가(가장 깊을 때 캐릭터가 구름 칸에 완전히 겹침) 저절로 튀어오름. 위에 있으면 계속 튐
  - 먹구름: 닿으면 빠르게 아래로 떨어짐
  - 사다리: ↑/↓로 오르내림 (사다리 위에선 Space로 점프). 꼭대기는 밟고 설 수 있음
  - 공점: 겹친 채로 점프하면 공중에서도 점프
  - 밧줄: 점프 키를 누른 채 닿으면 매달림 → ←/→로 흔들수록 각도가 커지고, 가만히 있으면 점점 줄어듦 → 점프 키를 떼면 흔들리던 힘으로 날아감
- **구역** (타일과 겹쳐 놓는 투명한 영역)
  - 노란 구역: 안에서 2단 점프
  - 보라 구역: 안에서 무한 점프
  - 물: 아주 천천히 가라앉고 계속 점프(헤엄) 가능. 수면에서 점프하면 물 밖으로
- **배경**: 기본 배경 3개(초원 · 노을 · 밤) 또는 직접 색을 고른 단색 / 그라데이션 (맵마다 저장)
- 진행 상황(별·체크포인트)은 월드별로 브라우저에 저장됨
- 기본 월드 1 오른쪽(x 80 이후)에 새 블록들을 차례로 체험하는 코스가 있고, 맨 끝(x 231 이후)에 코드 블록 예시(움직이는 발판 · 밟고 점프하면 사라지는 발판 · 머리로 박으면 바뀌는 ? 블록 · 도는 가시)가 있음

### 판정 (히트박스)
- 블록 그림 8x8 픽셀이 곧 판정: **색을 칠한 픽셀과 투명 픽셀은 판정이 있고, 비운 픽셀은 판정이 없음**
  - 투명 픽셀은 안 보이지만 밟을 수 있고 가시라면 찔림 (보이지 않는 벽·발판을 만들 때)
  - 예: 위쪽 절반을 비운 일반 블록은 반 칸 높이 발판, 계단 모양으로 칠하면 계단
- 단단한 블록(일반·얼음·머신·벽)과 가시류는 픽셀 단위 판정, 구름·먹구름·사다리·공점은 그린 픽셀을 감싸는 사각형 범위, 빈칸(장식)은 판정 없음
- 블록을 돌리면(에디터의 `R`, 코드의 `rot`) 판정도 **돌아간 각도대로** 돌아감. 45도처럼 비스듬한 각도도 그대로 따라감
- 코드로 움직이거나 도는 블록 위에 서 있으면 같이 실려 가고(도는 블록이면 함께 돌아감), 옆에서 밀리고, 블록 사이에 끼면 죽음

### 맵 에디터 (개발자 인증 필요)
- 플레이 화면 오른쪽 위 `개발자` 버튼 또는 월드 선택 화면 아래 `개발자` 버튼 → 인증 코드 입력
- **월드 관리** (인증 후 월드 선택 화면)
  - `+ 월드 추가`: 이름과 **열리는 데 필요한 별**(모든 월드에서 모은 별 합계 기준, 0이면 처음부터 열림)을 정해 새 월드를 만듦. 처음엔 스타트와 작은 땅만 있는 맵
  - 카드의 `⚙`: 이름 · 필요한 별 바꾸기, 직접 추가한 월드는 삭제(두 번 눌러 확인, 맵·진행 상황도 지워짐). `js/worlds.js`에 들어 있는 월드는 지울 수 없음
  - `worlds.js로 내보내기`: 이 브라우저의 월드들(이름 · 필요한 별 · 맵)을 `js/worlds.js`의 `const WORLDS = [...]` 부분에 그대로 붙여넣을 코드로 만들어 줌 → 붙여넣으면 모든 사람에게 보임
- **무한한 공간**: 가로·세로 모두 끝없이 이동하며 편집 (음수 좌표 가능)
- 왼쪽 팔레트: 선택 · 지우개 · 스타트 · 체크포인트 · 별 · 밧줄 · 구역 3종, 그리고 블록 디자인들 (선택하면 아래에 설명과 블록 태그 표시)
- **선택 도구**
  - 끌어서 영역 선택 → 영역 안을 끌면 **복사본을 끌어다 놓기**, Shift를 누른 채 끌면 옮기기
  - `Ctrl+C` 복사 · `Ctrl+X` 잘라내기 · `Ctrl+V` 붙여넣기(마우스를 따라다니는 미리보기를 클릭할 때마다 찍힘, 우클릭/Esc로 끝) · `Delete` 지우기
  - 한 칸을 고르면 속성: 체크포인트 **이름**, 밧줄 **길이**(숫자 입력 · −/+), 블록이면 블록 태그와 **코드** 버튼
- **블록 태그**: 디자인마다 다른 번호. 팔레트 설명·툴팁에 표시되고, 툴바 `태그`(T)를 켜면 놓인 블록마다 번호가 보임
- 스타트는 맵에 딱 1개: 새 위치에 놓으면 옮겨지고, 다른 도구로 덮거나 지울 수 없음
- 밧줄: 고정점을 누른 채 아래로 끌어서 원하는 길이로
- 블록은 `R`로 90도씩 회전(머신은 `R`로 방향 바꾸기), 단일 가시는 `Q`로 위치 바꾸기 (팔레트 버튼으로도 가능)
- 지우개/우클릭: 타일을 먼저 지우고, 타일이 없으면 구역을 지움 (구역 도구로 우클릭하면 구역만)
- `배경`: 기본 배경 3개 / 단색 / 그라데이션(시작 색 · 끝 색 · 방향) 중 고르기. 고르는 대로 바로 보이고 취소하면 되돌아감
- **블록 디자인**: 블록을 원하는 그림으로 만든 "디자인"을 여러 개 만들어 골라 쓸 수 있음
  - `+ 새로`로 종류를 고르고 8x8 픽셀에 색을 찍어 만듦. 색은 색상 선택기로 어떤 색이든 고를 수 있음 (16진 입력 가능)
  - 종류: 일반 블록 / 빈칸(장식) / 가시 / 단일 가시 / 큰 가시 / 얼음 / 머신 / 벽 / 구름 / 먹구름 / 사다리 / 공점
  - 종류와 상관없이 **8x8 전체**에 그릴 수 있음. `투명`(하늘색 빗금, 판정 있음) · `비우기`(체크무늬, 판정 없음)도 색처럼 골라 칠함
  - 픽셀 위에 마우스를 올리면 몇 번 픽셀인지 표시 (코드의 `px` · `pxColor` 번호)
  - **빈칸(장식)** 디자인은 통과할 수 있는 장식 블록
  - 팔레트 항목 더블클릭 또는 `편집`으로 수정 (이미 놓인 블록에도 바로 반영), `복제`, `삭제`(그 디자인으로 놓은 블록도 함께 지워짐)
  - 예전에 만든 맵이라 어떤 종류의 디자인이 없으면 그 종류의 기본 디자인이 팔레트에 채워짐
- **블록 코딩**: 블록을 선택 도구로 고르고 `코드 넣기`(또는 팔레트 `코드`)를 눌러 코드를 씀 (아래 '블록 코드' 참고)
  - 코드가 없던 블록에 처음 넣으면 **코드가 든 새 블록(새 태그)** 이 팔레트에 생겨서 그것을 골라 여러 곳에 놓을 수 있음 (`{}` 표시)
  - 코드가 든 블록의 코드를 고치면 그 태그로 놓은 블록 모두에 적용
  - 코드 창 아래 **죽어도 진행**을 켜면 그 블록은 캐릭터가 죽어도 되돌아가지 않고 코드를 계속 실행
  - 코드 창: 줄 번호, 쓰는 동안 문법 검사(틀린 줄 빨간색), 오른쪽 명령어 목록을 누르면 커서 자리에 들어감, Tab 들여쓰기 · Enter 자동 들여쓰기 · Ctrl+S 저장
  - 테스트 플레이 중 코드가 실행 중에 멈추면 아래 상태 줄에 블록 위치와 몇 번째 줄인지 표시
- 열려 있는 동안 **1분마다 자동 저장** (변경 사항이 있을 때). 에디터를 나가거나 탭을 닫을 때도 저장
- `테스트`로 편집 중인 맵을 바로 플레이 (이때 먹은 별·체크포인트는 저장되지 않음)
- `맵 문자열`에서 현재 맵 문자열을 복사하거나, 다른 문자열을 붙여넣어 적용. `기본 맵 불러오기`로 기본 맵 복원 가능

## 블록 코드

파이썬처럼 한 줄에 하나씩 쓰고, `:`로 끝나는 줄 아래는 들여써서 묶습니다. `#` 뒤는 주석입니다 (`#ff0000`처럼 `#`+16진 6자리는 색).

```
# 좌우로 왔다 갔다 하는 발판
wT:
    until cooX() >= 241:
        move(0.04, 0)
    wait(0.5)
    until cooX() <= 235:
        move(-0.04, 0)
    wait(0.5)
```

- 좌표는 **칸** 단위 (y는 아래로 갈수록 커짐, 에디터 상태 줄의 칸 좌표와 같음), 각도는 **도** (0 위 · 90 오른쪽 · 180 아래 · 270 왼쪽)
- 반복(`wT`, `until`)은 **한 바퀴에 한 프레임**(1/60초) 쉬고, `wait(A)`는 A초 쉼
- 블록마다 자기 코드를 따로 돌림. 처음 쓰는 변수에 `+=`하면 0부터 시작
- **변수**: 보통 변수는 그 블록 하나에만 있음 (다른 블록에 같은 이름이 있어도 서로 다른 변수). 이름이 **`_`로 끝나는 변수**(예: `점수_`)는 그 월드의 모든 블록이 같이 씀
- 코드 블록은 플레이 중에 움직일 수 있음: 위에 서 있으면 같이 실려 가고, 옆에서 밀리고, 블록 사이에 끼면 죽음. 판정은 돌린 각도대로 ('판정' 참고)
- **캐릭터가 죽으면** 코드 블록이 모두 처음 상태(위치 · 각도 · 투명도 · 픽셀 · 모양 · 변수)로 돌아가 코드를 처음부터 다시 실행 (`_` 변수도 처음 값으로)
  - `perm()`: 지금 상태를 저장 → 죽으면 처음이 아니라 저장한 상태(그때의 변수 · `_` 변수 포함)에서 코드를 처음부터 다시 실행
  - 코드 창에서 **죽어도 진행**을 켠 블록은 죽어도 되돌아가지 않고 하던 코드를 그대로 계속 실행

| 코드 | 뜻 |
| --- | --- |
| `blockTag()` | 이 블록의 블록 태그 |
| `convert(A)` | 블록 태그가 A인 블록으로 변환 (모양·성질이 바뀌고, 지금 코드는 계속 돎) |
| `rot(A)` | A도만큼 회전 |
| `if 조건:` / `else:` | 만일 조건이라면 / 아니면 |
| `wT:` | 계속 반복 |
| `until 조건:` | 조건이 될 때까지 반복 |
| `Tran(A)` / `TranPlus(A)` | 투명도를 A로 / A만큼 바꾸기 (0 불투명 ~ 100 투명) |
| `move(A, B)` | x로 A칸, y로 B칸 이동 |
| `cooX()` / `cooY()` | 블록 x / y좌표 |
| `A = B` / `A += B` / `A -= B` | 변수 A를 B로 / B만큼 더하기 / 빼기 |
| `px(A, #ff0000)` | A번 픽셀(1~64, 왼쪽 위부터 오른쪽으로)을 그 색으로 |
| `pxColor(A)` | A번 픽셀의 색 (투명이면 `""`) |
| `disapp()` / `appear()` | 사라지기(안 보이고 통과) / 나타나기 |
| `dis` / `app` | 사라져 있는가? / 나타나 있는가? |
| `wait(A)` | A초 기다리기 |
| `rotMove(A, B)` | A도 방향으로 B칸 이동 |
| `jump` | 캐릭터가 이 블록 위에서 점프했는가? |
| `noKey(A)` / `yesKey(A)` | A키 막기 / 다시 풀기 (`left` `right` `up` `down` `jump` `space`, 알파벳 한 글자. 죽거나 체크포인트로 돌아가면 풀림) |
| `caCooX()` / `caCooY()` | 캐릭터 x / y좌표 (캐릭터가 서 있는 칸 기준) |
| `caTp(A, B)` | 캐릭터를 칸 (A, B)로 보내기 |
| `kill()` | 캐릭터 죽이기 |
| `perm()` | 지금 상태 저장 (죽으면 이 상태로 돌아감) |
| `headbutt` | 캐릭터가 머리를 여기 박았는가? |
| `stick` | 캐릭터가 이 블록 옆면에 붙어 있는가? |
| `+ - * /` · `//` · `%` | 사칙연산 · 몫 · 나머지 |
| `== != < > <= >=` · `and or not` | 비교 · 논리 |
| `sin(A)` `cos(A)` `tan(A)` `abs(A)` | 삼각함수(도) · 절대값 |

`jump`와 `headbutt`는 일어난 뒤 코드가 한 번 확인할 때까지 참으로 남아 있어서, `wait` 중에 일어나도 놓치지 않습니다.

## 맵 문자열 형식

맵 하나(블록 디자인 · 코드 · 구역 · 배경 포함)는 문자열 하나로 저장됩니다. `;`로 나뉜 8부분입니다.

```
PAR5;<배경>;<디자인들>;<타일 목록>;<원점x>,<원점y>;<행들>;<구역 원점x>,<구역 원점y>;<구역 행들>
```

- **배경**: `p0` 초원 · `p1` 노을 · `p2` 밤 · `s<색>` 단색 · `g<색>+<색>+<방향>` 그라데이션 (방향 `v` 위→아래 · `h` 왼→오른 · `d` ↘ · `u` ↗)
- **디자인들**: 쉼표로 구분. 각 디자인은 `<종류><색들>:<픽셀 64자>:<블록 태그>:<설정>:<코드>`
  - 종류: `B` 일반 블록 · `D` 빈칸(장식) · `T` 가시 · `U` 단일 가시 · `K` 큰 가시 · `I` 얼음 · `M` 머신 · `W` 벽 · `C` 구름 · `N` 먹구름 · `H` 사다리 · `O` 공점
  - 색들: 16진 색을 `+`로 연결 (예: `7bd67f+4caf50`)
  - 픽셀: 위 행부터 8x8. `.`은 비움(판정 없음), `~`는 투명(판정 있음), 나머지는 색 번호(`0-9a-zA-Z-_`)
  - 설정: `k` 죽어도 진행 (없으면 빈칸)
  - 코드: URL 인코딩한 블록 코드 (없으면 빈칸)
- **타일 목록**: 행에서 쓰는 블록 글자의 뜻. 쉼표로 구분하고 순서대로 `A`, `B`, `D`, `E`, …가 배정
  - `<디자인 번호>[p<위치 0-2>][r<회전 0-3>][m<방향 0 왼쪽 · 1 오른쪽>]` (예: `3p0r1`)
  - `~<길이>` 밧줄 (예: `~5`) · `c<이름>` 이름 붙은 체크포인트 (이름은 URL 인코딩)
- **원점**: 맨 위 행 맨 왼쪽 칸의 좌표 (음수 가능)
- **행들**: `/`로 구분. 칸마다 한 글자이고, 앞에 숫자가 붙으면 그만큼 반복 (예: `12.` = 빈칸 12개)
  - `.` 빈칸 · `S` 스타트(정확히 1개) · `C` 이름 없는 체크포인트 · `*` 별 · 그 외는 타일 목록의 글자
- **구역 행들**: 행들과 같은 방식. `.` 없음 · `Y` 노란 구역 · `P` 보라 구역 · `W` 물

이전 형식(`PAR4;`, `PAR3;`, `PAR2;`, `PAR1:`)으로 저장된 맵도 불러올 수 있고(블록 태그가 없던 형식은 팔레트 순서대로 1, 2, 3…), 저장하면 `PAR5`로 바뀝니다.

## 저장 위치

맵과 진행 상황, 개발자가 추가·수정한 월드 정보는 **이 브라우저의 localStorage**에만 저장됩니다
(`par.world<번호>.map`, `par.world<번호>.progress`, `par.worlds`).
다른 브라우저/기기나 다른 사람에게는 반영되지 않으므로, 게임 기본값으로 확정하려면
월드 선택 화면의 `worlds.js로 내보내기`로 만든 코드로 `js/worlds.js`의 `WORLDS`를 바꾸면 됩니다
(맵 하나만이라면 `맵 문자열`에서 복사해 그 월드의 `defaultMap`에 넣어도 됨).

# Par

브라우저에서 돌아가는 2D 플랫포머 게임입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 현재 기능

### 플레이
- **월드 선택**: 지금은 월드 1만 있음 (`js/worlds.js`에 항목을 추가하면 늘어남). 카드에 모은 별 개수 표시
- **이동/점프**: 길게 누르면 높이, 짧게 누르면 낮게 점프
- **체크포인트**: 스타트 포함. 직접 가서 닿아야 등록되고, 마지막으로 닿은 체크포인트에서 부활
  - `C` 키(또는 `체크포인트` 버튼)로 등록한 체크포인트 아무 데나 이동 가능 — **떨어지는 중에는 이동 불가**
- **별**: 닿으면 획득해서 별 개수 +1. 한 번 먹은 별은 다시 먹을 수 없음
- **가시**: 닿으면 죽고 현재 체크포인트에서 부활. 에디터에서 90도씩 돌려 놓을 수 있음 (위·오른쪽·아래·왼쪽)
  - 가시: 1/3 크기 삼각형 가시 3개가 붙은 모양
  - 단일 가시: 1/3 크기 가시 1개 (왼쪽 · 가운데 · 오른쪽 중 골라서 놓음)
  - 큰 가시: 칸 크기 삼각형 가시
- **특수 블록**
  - 얼음: 위에서 미끄러짐
  - 머신: 위에 있으면 가만히 있어도 왼쪽/오른쪽(놓을 때 고름)으로 이동
  - 벽: 옆에 딱 붙어 있으면 아래에 블록이 없어도 계속 점프 가능 (벽 타고 오르기)
  - 구름: 닿기만 하면 파묻혔다가(가장 깊을 때 캐릭터가 구름 칸에 완전히 겹침) 저절로 튀어오름. 위에 있으면 계속 튐
  - 먹구름: 닿으면 빠르게 아래로 떨어짐
  - 사다리: ↑/↓로 오르내림 (사다리 위에선 Space로 점프). 꼭대기는 밟고 설 수 있음
  - 공점: 겹친 채로 점프하면 공중에서도 점프
  - 밧줄: 점프 키를 누른 채 닿으면 매달림 → ←/→로 흔들수록 각도가 커지고, 가만히 있으면 점점 줄어듦 → 점프 키를 떼면 흔들리던 힘으로 날아감
- **구역** (타일과 겹쳐 놓는 투명한 영역)
  - 노란 구역: 안에서 2단 점프
  - 보라 구역: 안에서 무한 점프
  - 물: 아주 천천히 가라앉고 계속 점프(헤엄) 가능. 수면에서 점프하면 물 밖으로
- **배경**: 기본 배경 3개(초원 · 노을 · 밤) 또는 직접 색을 고른 단색 / 그라데이션 (맵마다 저장)
- 진행 상황(별·체크포인트)은 월드별로 브라우저에 저장됨
- 기본 월드 1 오른쪽(x 80 이후)에 새 블록들을 차례로 체험하는 코스가 있음

### 맵 에디터 (개발자 인증 필요)
- 플레이 화면 오른쪽 위 `개발자` 버튼 → 인증 코드 입력
- **무한한 공간**: 가로·세로 모두 끝없이 이동하며 편집 (음수 좌표 가능)
- 왼쪽 팔레트: 지우개 · 스타트 · 체크포인트 · 별 · 밧줄 · 구역 3종, 그리고 블록 디자인들 (선택하면 아래에 설명 표시)
- 스타트는 맵에 딱 1개: 새 위치에 놓으면 옮겨지고, 다른 도구로 덮거나 지울 수 없음
- 밧줄: 고정점을 누른 채 아래로 끌어서 원하는 길이로
- 가시는 `R`로 90도씩 회전, 머신은 `R`로 방향 바꾸기, 단일 가시는 `Q`로 위치 바꾸기 (팔레트 버튼으로도 가능)
- 지우개/우클릭: 타일을 먼저 지우고, 타일이 없으면 구역을 지움 (구역 도구로 우클릭하면 구역만)
- `배경`: 기본 배경 3개 / 단색 / 그라데이션(시작 색 · 끝 색 · 방향) 중 고르기. 고르는 대로 바로 보이고 취소하면 되돌아감
- **블록 디자인**: 블록을 원하는 그림으로 만든 "디자인"을 여러 개 만들어 골라 쓸 수 있음
  - `+ 새로`로 종류를 고르고 8x8 픽셀에 색을 찍어 만듦. 색은 색상 선택기로 어떤 색이든 고를 수 있음 (16진 입력 가능)
  - 종류: 일반 블록 / 빈칸(장식) / 가시 / 단일 가시 / 큰 가시 / 얼음 / 머신 / 벽 / 구름 / 먹구름 / 사다리 / 공점
  - 삼각형인 가시류는 모양 밖 픽셀이 투명으로 고정 (편집 화면에서 빗금 칸)
  - **빈칸(장식)** 디자인은 통과할 수 있는 장식 블록
  - 팔레트 항목 더블클릭 또는 `편집`으로 수정 (이미 놓인 블록에도 바로 반영), `복제`, `삭제`(그 디자인으로 놓은 블록도 함께 지워짐)
  - 예전에 만든 맵이라 어떤 종류의 디자인이 없으면 그 종류의 기본 디자인이 팔레트에 채워짐
- 열려 있는 동안 **1분마다 자동 저장** (변경 사항이 있을 때). 에디터를 나가거나 탭을 닫을 때도 저장
- `테스트`로 편집 중인 맵을 바로 플레이 (이때 먹은 별·체크포인트는 저장되지 않음)
- `맵 문자열`에서 현재 맵 문자열을 복사하거나, 다른 문자열을 붙여넣어 적용. `기본 맵 불러오기`로 기본 맵 복원 가능

## 맵 문자열 형식

맵 하나(블록 디자인 · 구역 · 배경 포함)는 문자열 하나로 저장됩니다. `;`로 나뉜 8부분입니다.

```
PAR3;<배경>;<디자인들>;<타일 목록>;<원점x>,<원점y>;<행들>;<구역 원점x>,<구역 원점y>;<구역 행들>
```

- **배경**: `p0` 초원 · `p1` 노을 · `p2` 밤 · `s<색>` 단색 · `g<색>+<색>+<방향>` 그라데이션 (방향 `v` 위→아래 · `h` 왼→오른 · `d` ↘ · `u` ↗)
- **디자인들**: 쉼표로 구분. 각 디자인은 `<종류><색들>:<픽셀 64자>`
  - 종류: `B` 일반 블록 · `D` 빈칸(장식) · `T` 가시 · `U` 단일 가시 · `K` 큰 가시 · `I` 얼음 · `M` 머신 · `W` 벽 · `C` 구름 · `N` 먹구름 · `H` 사다리 · `O` 공점
  - 색들: 16진 색을 `+`로 연결 (예: `7bd67f+4caf50`)
  - 픽셀: 위 행부터 8x8. `.`은 투명, 나머지는 색 번호(`0-9a-zA-Z-_`)
- **타일 목록**: 행에서 쓰는 블록 글자의 뜻. 쉼표로 구분하고 순서대로 `A`, `B`, `D`, `E`, …가 배정
  - `<디자인 번호>[p<위치 0-2>][r<회전 0-3>][m<방향 0 왼쪽 · 1 오른쪽>]` (예: `3p0r1`)
  - `~<길이>` 밧줄 (예: `~5`)
- **원점**: 맨 위 행 맨 왼쪽 칸의 좌표 (음수 가능)
- **행들**: `/`로 구분. 칸마다 한 글자이고, 앞에 숫자가 붙으면 그만큼 반복 (예: `12.` = 빈칸 12개)
  - `.` 빈칸 · `S` 스타트(정확히 1개) · `C` 체크포인트 · `*` 별 · 그 외는 타일 목록의 글자
- **구역 행들**: 행들과 같은 방식. `.` 없음 · `Y` 노란 구역 · `P` 보라 구역 · `W` 물

이전 형식(`PAR2;`, `PAR1:`)으로 저장된 맵도 불러올 수 있고, 저장하면 `PAR3`으로 바뀝니다.

## 저장 위치

맵과 진행 상황은 **이 브라우저의 localStorage**에만 저장됩니다 (`par.world1.map`, `par.world1.progress`).
다른 브라우저/기기나 다른 사람에게는 반영되지 않으므로, 맵을 게임 기본값으로 확정하려면
`맵 문자열`에서 복사해 `js/worlds.js`의 `defaultMap`에 넣어야 합니다.
